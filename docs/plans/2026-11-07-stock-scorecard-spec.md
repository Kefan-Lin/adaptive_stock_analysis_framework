## Problem Statement

现有股票研究体系已有行业分析、护城河、财务诊断、资本配置、估值和决策记录，但缺少统一且可持续维护的研究打分卡。用户难以快速辨认每项判断的质量、证据可信度、未知项和历次变化；现有决策记录同日同模式重跑会覆盖，也不足以保存不可变评分历史。

直接用新评分替换既有护城河或财务评分，可能悄然改变终值、估值或仓位判断。该功能必须增强研究记忆与可复核性，同时保护既有估值模式、旧记录和私人研究数据。

## Solution

首版打通“完整研究或局部复核 → 三层研究打分卡 → 私人不可变评分快照 → 历史变化对比 → 可选决策引用”。

- 公司质量卡：八个独立维度，每维 1–5 分整数或明确无分数状态，另附高/中/低可信度；不计算跨维度总分。
- 价格吸引力卡：引用既有估值的情景、合理价值、安全边际、市场隐含预期及口径/时点，不生成另一套估值。
- 决策条件卡：展示证据缺口、重大问题、投资逻辑及证伪条件、组合适配和执行条件。
- 在原十章报告的摘要中集中呈现紧凑卡片，详细论证引用正文；局部复核明确本次更新与沿用项。
- 每次完成的研究或明确复核保存独立快照，即使尚无投资结论；后续更新和修正都不能覆盖原快照。
- 新卡仅用于展示与复核，不通过分数自动决定买卖或仓位，不新增自动交易禁令，也不撤销既有流程限制。

## User Stories

1. As an 投资研究者, I want 在摘要看到三层卡片, so that 我能分别判断公司、价格和决策条件。
2. As an 投资研究者, I want 逐项查看八个质量维度, so that 单项弱点不会被总分掩盖。
3. As an 投资研究者, I want 统一的分数锚点, so that 不同时间的评分具有可解释性。
4. As an 投资研究者, I want 质量分与可信度分开, so that 初步判断不会被误认成充分证实。
5. As an 投资研究者, I want 信息不足时不给分, so that 未知不会被伪装成中等或低质量。
6. As an 投资研究者, I want 不适用时说明理由, so that 行业差异不会导致机械扣分。
7. As an 投资研究者, I want 每项判断附支持证据及来源日期, so that 我能追溯其依据。
8. As an 投资研究者, I want 查看反证或反证检索说明, so that 单方叙事受到检验。
9. As an 投资研究者, I want 区分事实、管理层说法和分析推断, so that 我能识别假设成分。
10. As an 投资研究者, I want 记录待解问题和复核触发条件, so that 后续研究有明确方向。
11. As an 投资研究者, I want 独立查看待核实及已确认的重大问题, so that 严重风险不会被其他高分淹没。
12. As an 投资研究者, I want 行业适配的指标, so that 银行或尚未商业化企业不会被不适用的普通企业指标误判。
13. As an 投资研究者, I want 分清当前产品竞争力与护城河持续性, so that 优势的存在和耐久性不会混为一谈。
14. As an 投资研究者, I want 以长期行为、激励和小股东待遇评价管理层, so that 人物魅力不会代替治理证据。
15. As an 投资研究者, I want 价格卡保留原估值口径和时点, so that 我不会将不同模式的数字错误比较。
16. As an 投资研究者, I want 缺估值或组合资料时明确留空, so that 卡片不会为完整外观伪造结论。
17. As an 投资研究者, I want 新旧评分分别命名并解释冲突, so that 新卡不会偷偷替换原模型输入。
18. As an 投资研究者, I want 完整研究后保存快照, so that 当前判断能够长期回看。
19. As an 投资研究者, I want 无买卖结论的研究也能保存, so that 研究积累不依赖虚构 stance。
20. As an 投资研究者, I want 局部复核只更新选定项目, so that 其他项目不会被误标为重新确认。
21. As an 投资研究者, I want 沿用项保留原评估日期和来源版本, so that 我能识别陈旧判断。
22. As an 投资研究者, I want 同日多次研究各有独立快照, so that 评分演化不会丢失。
23. As an 投资研究者, I want 错误以关联原快照的新修正版纠正, so that 历史记录保持诚实。
24. As an 投资研究者, I want 变化区分新事实、假设变化、规范变化与错误修正, so that 我能解释分数及证据为什么变化。
25. As an 投资研究者, I want 跨规范版本指出不可直接比较项, so that 方法变化不会被误认成公司变化。
26. As an 投资研究者, I want 纯股价变化不改变质量分或内在价值, so that 市场波动不会倒推企业判断。
27. As an 投资研究者, I want 决策引用具体快照, so that 后续更新不会改变当次引用的评分依据。
28. As an 投资研究者, I want 旧记录继续可读且不补造历史分, so that 旧工作可用而不产生后见之明。
29. As an 投资研究者, I want 实际研究保存在私人数据目录, so that 公共仓库只包含规则与虚构样例。
30. As an 维护者, I want 用实际读写与校验行为测试保存链路, so that 文档文字通过检查不被误当成功能正确。
31. As an 维护者, I want 用虚构报告样例审阅证据、行业适配与展示, so that 分析内容质量有独立验收依据。
32. As an 投资研究者, I want 保存失败时明确获知未持久化, so that 我不会以为不存在的历史版本已经保存。

## Implementation Decisions

以下业务边界来自已确认的 Q1–Q15 和 ADR-0001/0002；接口细节是其实现约束，不授权改变评分或估值模式。使用项目术语表，不将术语表作为规格或实现草稿。

### 1. 模块边界与接入

- 通用评分规范只有一个权威定义，包含维度、锚点、证据契约、可信度、重大问题和版本规则。
- 分析控制器在已有分析与输入核验完成后组装卡片；行业 companion 提供适用指标、证据及适用性说明，不各自复制评分体系。
- 管理层与治理评价、资本配置评价补齐长期行为与每股价值证据；沿用已有行业、商业模式、财务、证据台账和估值模块。
- 报告模板和决策工作流消费同一份卡片，避免分别生成相互矛盾的评分。摘要呈现紧凑三卡，正文对应部分提供依据。
- 新增一个集中的评分快照持久化边界，提供校验、创建、读取及比较的公开操作；控制器和工作流通过此边界保存，而非自行覆写快照。
- 沿用已有完整研究和增量/事件复核路径，不另造一套 full/quick/valuation-only 产品模式。

### 2. 质量判断与证据契约

每个完整快照均表示八个质量维度。各维度至少包含稳定的维度标识、评估状态、分数、可信度、判断理由、支持证据、反证或检索说明、待解问题、复核触发条件、原评估时点和本次复核状态。

- 状态为已评估、信息不足、不适用。已评估必须为 1–5 整数且有独立可信度；未知或不适用的分数为空，拒绝用 0、3、布尔值或小数代替状态。
- 未形成判断时可信度可为空，不以“低可信度”代替信息不足。不适用必须给出理由。
- 证据至少包含来源定位、来源日期、相关事实或说法摘要及类型；类型区分事实、管理层说法、分析推断，推断说明所依赖证据和假设。
- 无反证时保留检索范围说明，不要求编造反证或机械凑足来源条数。没有足够检索材料时明确尚未核查。
- 信息不足项仍保留已知材料与具体缺口；未检索或无证据不能假装完成研究。
- 同一证据可供不同维度引用，但须解释各自判断含义，不产生重复加权奖励。
- 原评估日期、信息截至时点与新快照创建时点分开表达。沿用旧判断不得更新成今天；不能用之后获知的信息伪装过去已知的事实。

### 3. 评分锚点

| 维度 | 1 分：明显薄弱 | 3 分：中等、优劣并存 | 5 分：突出且可持续 |
| --- | --- | --- | --- |
| 行业经济性 | 长期供过于求、议价弱，价值难留在行业内 | 有合理盈利空间，但竞争或周期约束明显 | 需求韧性强，供给纪律和价值分配有利于长期回报 |
| 商业模式 | 单位经济性差，规模扩大仍难改善 | 盈利机制成立，但受成本、资本投入等约束 | 客户价值可稳定转化为股东收益，规模与资本效率良好 |
| 产品竞争力 | 客户持续流失，产品性价比或效果落后 | 能满足需求，与竞争者各有优劣 | 客户选择、留存及付费行为体现明显优势 |
| 护城河持续性 | 优势易被复制，替代或侵蚀正在发生 | 存在一定壁垒，但耐久性有限 | 优势难以复制，竞争与技术变化下仍能维持 |
| 管理层与治理 | 已证实严重失信、利益侵占或长期执行失当 | 能力与治理表现有好有坏 | 长期兑现承诺，激励合理，公平对待小股东 |
| 资本配置与再投资 | 投资、并购或融资持续损害每股价值 | 配置结果参差，整体回报合理 | 再投资及现金分配有纪律，持续提升每股价值 |
| 盈利与现金质量 | 盈利失真或不可持续，现金与利润长期背离且解释不足 | 盈利基本可信，但波动、一次性项目或转化存在约束 | 盈利来源可持续、会计稳健，适用的现金或收益质量指标良好 |
| 财务韧性 | 流动性、偿债或融资风险可能威胁持续经营 | 正常情况下可承受，压力情景下有明显弱点 | 在合理压力情景下仍有充足缓冲与融资自主性 |

2 分和 4 分用于相邻档之间，理由须说明符合条件和剩余差距。资料缺失不能打 1 分或 3 分；不按单一指标机械映射分数。产品竞争力评价当前客户选择，护城河评价优势持续性。

可信度分档：
- 高：关键判断有直接可追溯证据，覆盖必要时期，重要矛盾已解释。
- 中：足以形成判断，但历史覆盖、独立验证或关键细节仍有缺口。
- 低：只支持初步判断，较依赖单方说法、间接指标或较强假设，列出待验证项。
- 不足以支持初步判断：信息不足且不评分。官方披露不自动等于高可信度，转载不等于独立证据。

### 4. 行业适配

八个维度语义一致，由现有行业及诊断家族选择适用指标。银行的财务韧性使用资本、资产质量与流动性等指标，不强制净债务/EBITDA或普通企业FCF。房地产、保险及其他家族同样遵守现有适用性规则。

尚未商业化企业不能仅因没有收入在盈利与现金质量项得 1 分，应判断适用性，同时评价现金消耗、融资依赖和财务韧性。表现差与资料不足均不是不适用的理由。管理层评价采用行为、承诺兑现、激励、执行及小股东待遇，不从人物魅力或高调低调推导诚信。

### 5. 价格吸引力与决策条件

价格卡引用原报告的情景、合理价值、安全边际、隐含预期，保留币种、价格及估值时点、主方法、盈利/现金流口径、预测期限和情景含义。不强制旧框架原本没有的估值输出，也不为填卡创造新模型。

决策条件卡保留重大问题证据状态、影响、核查事项，以及投资逻辑、证伪条件、证据缺口、组合适配及执行条件。没有估值或组合材料时标明尚未评估/信息不足。

待核实疑点不直接定性为欺诈；已确认重大问题独立显著呈现，不被高分抵消。不设置评分到买卖、仓位或交易禁令的自动映射；既有流程的独立限制继续有效。

### 6. 估值模式保护与旧评分兼容

新质量分具有独立名称与规范版本，不能替换或机械换算既有 0–5 护城河和财务评分；冲突说明双方衡量对象并触发复核。

评估已有股票前读取既有报告与决策记录，识别原框架、主方法、盈利/现金流口径、估值时点、期限和 Bear/Base/Bull 含义。新卡、新 gate、重估、完整重跑、错误修复或第二意见均不自动授权模式变更；这条用户约束优先于既有 gate 可能被解释为换模式授权的表述。

允许在原模式内更新有来源的输入、修正明确算术错误并解释影响；只组装卡片时不得主动重估。旧模式存在限制时指出限制，不能替换模式或把沿用旧值说成重新确认。获准模式变更须记录许可、日期并保留旧模型，区分事实、方法和假设变化。首次覆盖遵循用户认可的框架。

纯价格变化只影响价格相关信息，不因此改变质量分或内在价值；若存在融资压力等真实经营传导，应以独立事实和原因记录支持变化。

### 7. 快照、局部复核与比较

- 使用独立版本化快照契约，包含快照标识、规范版本、结构版本、canonical symbol/市场、创建时点、信息截至时点、复核范围、三卡内容、证据和来源报告定位；有前版或修正对象时保存精确引用。
- 实际股票数据使用现有私人 state-home 的独立研究存储区域，不混入会被旧决策记录校验器直接扫描的记录文件集合。
- 快照标识须支持同日多次更新。写入须先校验、无覆盖创建；标识冲突或写入失败不得损坏原文件或伪报成功。读取及比较操作不得改写源快照。
- 完整研究和明确局部复核完成后保存；临时聊天不自动保存正式评分；没有 stance 或 execution_method 的研究也能独立保存。
- 局部更新指定被复核项目及明确基线，沿用项保留分数、证据、原评估日期和来源快照，并标记本次未复核。首次局部研究没有历史的其他维度显示尚无判断/信息不足，不能伪造沿用数据。
- 错误修正生成关联原版的新快照。规范升级生成新版本，不回写历史；跨规范比较不直接输出误导性的升降分结论。
- 比较指定的两个版本，输出分数、状态、可信度、证据、问题、价格卡或条件卡等实际变化及原因；分数不变的证据更新也可被识别。
- 变化原因采用新事实、假设变化、评分规范变化、明确错误修正；组合变化可记录多种原因，不以“更新了”代替说明。
- 身份沿用既有 canonical tradable-line 规则，跨市场上市或 ADR 不因名称相似而合并；引用校验须保证目标存在且属于正确股票。
- state-home 不可用时沿用既有无状态退路：可以展示结果并明确未保存，不把私人数据写入公共仓库，也不声称存在快照引用。

### 8. 决策记录与报告契约

决策记录新增可选具体快照引用；有引用时验证目标与股票一致，没有引用的旧记录保持合法。不得使用会变化的 latest 充当历史依据，也不得为了保存纯研究而构造投资 stance。

不改变既有决策记录的身份或覆盖语义；快照历史独立保存，因此决策记录再次写入不改变此前快照。旧报告没有新卡时显示未按本版本评估，不追溯补分。

完整研究保留十章报告，摘要呈现三卡并指向正文相应论证。已有旧评分表保持原语义并明显区别于新质量卡。事件复核沿用现有增量输出方式，明确更新范围，不声称重新完成全报告。

## Testing Decisions

Q15 已确认测试边界：实际读写与校验验证保存链路，虚构报告样例单独验证内容与展示。优先复用现有决策记录测试中“复制虚构 state-home 到临时目录，再通过公开校验入口检查”的模式。

新增的主要行为测试边界是集中的快照创建/读取/比较及校验入口；不把测试绑定到内部 helper。兼容性测试通过现有决策记录校验和索引重建入口，必要时连同新快照校验运行。所有测试用虚构数据，不读取真实私人 state-home。

| 场景 | 可观察验收结果 |
| --- | --- |
| 完整研究保存 | 八维及三卡可读，分数、证据、来源日期与报告引用一致 |
| 非法评分 | 拒绝 0、6、小数、布尔值，以及未知/不适用带数字分数；有效 1–5 整数通过 |
| 证据与状态 | 已评估项缺必要依据或可信度时失败；不适用缺理由时失败；未知不被补成中等分 |
| 同日两次研究 | 两个独立版本均可读取，首版文件字节不变 |
| 局部复核 | 只更新指定项目，沿用项的原日期、证据及标记正确；无历史项不冒充已评估 |
| 明确错误修正 | 新版本关联原快照且修正可见，原版字节不变 |
| 写入冲突或失败 | 不覆盖既有快照、不产生可误认为有效的残缺快照、不返回保存成功 |

| 历史信息 | 创建时点与原评估日期不混淆，后知信息不能伪装成当时依据 |

## Out of Scope

- 自动买卖、自动仓位映射、跨维度加权总分，以及新评分驱动的自动交易禁令。
- 将旧护城河、财务评分迁移到新分数或重写旧估值模式。
- 未获许可的估值方法、盈利口径、预测期限或情景含义变更。
- 回填历史评分、将后知信息纳入当时成绩，或批量迁移私人历史报告。
- 晨检事件自动关联、自动改分和经营假设兑现复盘；现有收益复盘含义不变。
- 替换拐点筛选的独立评分体系。
- 新仪表盘、数据库迁移、网站、独立权限系统或全新研究模式。
- 本规格发布不执行实际股票研究、不读取用户持仓、不交易。
